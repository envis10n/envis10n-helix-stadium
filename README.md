# envis10n-helix-stadium

This is a repository of my presets for the new [Line 6 Helix Stadium Native](https://line6.com/helix-stadium-native-intro/) plugin.

Each preset has an accompanying .txt document describing the tone. (This information is also included in the preset info in the plugin.)

## Installation

1. Download this repository.
2. Place the folder `envis10n` into your preset folder.
   - Windows & macOS: Documents > Line 6 > Helix Stadium Native > Presets
3. In Helix Stadium Native, open the preset browser and the `envis10n` folder should show up.

### Input/Output Trim

If it sounds unexpected, double check that your input is properly trimmed to match -6db on your unprocessed input level. (This is the level I personally match to in amp sims.)
